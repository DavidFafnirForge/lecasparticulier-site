LE CAS PARTICULIER

Publisher

A private tool that sends finished videos from the channel Le Cas Particulier to its own TikTok account.

The tool has a single user: the owner of the TikTok account @LeCasParticulier. It has no sign-up, no public accounts and no third-party users. It uses TikTok's Login Kit once to authorise the account, then the Content Posting API in upload mode to drop each finished video into the owner's TikTok inbox, where the owner reviews it and publishes it.
