1. Purpose

The App transfers video files produced for the channel "Le Cas Particulier" from the owner's own server to the owner's own TikTok account, using TikTok's Content Posting API in upload (inbox) mode. The owner reviews and publishes each video manually inside the TikTok app.

2. Access

Access requires the account owner to authorise the App through TikTok's OAuth flow. The App stores the resulting access and refresh tokens on the owner's server and nowhere else. Access can be revoked at any time from the TikTok account settings (Security & permissions → Manage app permissions).
